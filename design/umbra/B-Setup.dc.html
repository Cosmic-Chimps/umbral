Set up Umbral

Choose the operator credential. It's the only way to reach this admin area, so keep it somewhere safe. There's no recovery screen: if you lose it, run this on the host.

docker exec -it umbral /app/Umbral reset-credential
Printed in the container's log when Umbral starts.
At least 12 characters. This is not tied to any connector, so a broken Discord or Google app can never lock you out.
